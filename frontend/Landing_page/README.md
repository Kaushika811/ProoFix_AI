# ProoFix landing page

This folder supplies the home page (`/`) of the main frontend. All Open workspace / Open app links lead to `/workspace`.

Run from `frontend/`:

```sh
npm install
npm run dev
```

Build with `npm run build` from the same directory. This folder uses the parent frontend dependencies, router, and build configuration; it needs no separate environment file or installation.

The previous landing page remains in `frontend/src/components/landing/`, and its standalone source remains in `frontend/Landing/`.
